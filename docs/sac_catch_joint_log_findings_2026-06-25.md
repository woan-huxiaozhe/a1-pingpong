## 3. joint5 转矩饱和与 PD 分解

- joint5 `tau` 峰值 = **8.00 Nm**(= 其 effort 上限),`|tau|>7.5 Nm` 的步占 **8/1564(0.51%)**。
- 纯 PD 重建 `tau = Kp(q_target−q) + Kd(qd_target−qd)`(Kp=120, Kd=0.5, 位置控制 `qd_target=0`):
  - 与 logged `tau` 相关性 **0.9677**,RMS 残差 0.433 Nm。
- 饱和步处分解:

  | 量 | 值 |
  |---|---|
  | 位置误差项 `Kp·(q_target−q)` | **+8.04 Nm(占 87.3%)** |
  | 速度项 `−Kd·qd` | −1.17 Nm(占 12.7%) |
  | 平均 \|位置误差\| | 0.0670 rad(3.84°) |
  | 触发 8 Nm 所需误差 `8/Kp` | 0.0667 rad(3.82°) |
  | 全程最大 \|位置误差\| | 0.0736 rad(4.21°) |
  | 饱和步平均 \|qd_sim\| | 2.34 rad/s(上限 20) |

- 观测:8 Nm 几乎全部来自**位置误差项**,误差幅度正好顶在 `8/Kp` 阈值附近。
- 其它关节接触时段转矩水平(参考):joint6 ≈ 6.99,joint4 ≈ 6.01,joint1-3 ≈ 14.5–16.8(上限 28);**无关节位置饱和**(joint5 工作区间约 0.006/−0.468,远离 ±2.758)。

## 4. 速度峰处的"外力减速"特征

逐 episode(env0,剔除复位行)在 joint5 速度峰附近取最大 `|加速度|` 步,记 `加速度 = Δqd_sim/dt`:

- **加速度量级**:上升沿约 `+33…+57 rad/s²`,峰后下降沿约 `−33…−66 rad/s²`。
- **符号判据**:下降沿那一步,关节以 `−50 rad/s²` 量级减速,但电机转矩仍为**正**(约 +2 Nm,推动方向与运动同向)。

  - **16/20 段**:加速度与转矩**反号**(关节顶着自身正转矩被减速)→ 存在外部减速力。
  - **4/20 段**(ep 1/16/18/20):同号,且速度峰恰在 episode 最后一步(`steps_from_end=0`),即采样止于上升沿。
- **时间位置**:速度峰普遍在 episode 终止前 **约 33 步(≈0.66 s)**;`qd_peak` 范围 0.84–3.00 rad/s。
- `[推断]` 正转矩无法使关节减速,需外力;该外力出现在挥拍速度峰、跨段一致。最可能为**球-拍碰撞反作用**(本 CSV 无接触力列,故为推断而非直接测量;未实测重力/耦合项贡献)。
